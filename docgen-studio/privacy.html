DocGen Studio

Privacy Policy

Last updated: August 23, 2026

DocGen Studio is a Chrome extension that records clicks on a page you choose, captures annotated screenshots of those clicks, and helps you turn the recording into a step-by-step SaaS how-to guide. You can export the guide as PDF or Markdown. Optional AI writing uses an API key that you provide.

Data we do not collect

DocGen Studio has no developer backend, analytics, advertising, or user accounts. We do not receive, sell, or share your data.

Data stored on your device

  • Your optional OpenRouter API key and model name, saved in Chrome local storage so the editor can draft titles and descriptions.
  • Your screenshot mode preference (focused crop or full screenshot).
  • Recorded steps, including screenshots and click metadata, held in extension memory until you stop recording, edit, or export. They are not uploaded to us.

Screenshots and page content

While recording, the extension captures the visible tab and the label, type, and on-screen position of elements you click. This can include personal or confidential information that is already visible on the page. Screenshots stay on your device unless you export them yourself.

Optional AI writing

If you add an OpenRouter API key, the editor sends click labels and element types (for example, “user clicked a button labeled Save”) to OpenRouter so a model can draft a document title, summary, and step text. Screenshot images are not attached to that request. Your key is sent only to OpenRouter as a bearer token. OpenRouter and the model provider you select have their own privacy policies. If you do not add a key, nothing is sent to OpenRouter and the editor uses local fallback text.

Permissions

The extension can run on websites you visit so recording can start on the page you are documenting. It uses tab access to capture the active page and to open the editor. It uses downloads only when you export Markdown. It does not read your browsing history for any other purpose.
